# Prerequisite

```
python -m venv .venv

source .venv/bin/activate

pip install -e .

cd ..

pip install -e .

cd ui/frontend

npm install -g gatsby-cli

npm install -g yarn

yarn install

yarn build

chmod +x run.sh

chmod +x run-github.sh
```

# Configure to run on github
- Open run-github.com

- Edit this line, `export export CODESPACE_ID="sturdy-robot-jwv4gq46j9gfpp7q"` to your codespace ID.

- Forward port 8000, 3000, 5000

# Run Web UI

```
cd frontend

./run-github.sh 
```
